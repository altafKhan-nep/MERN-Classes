Basic Commands:

    i.clone :- Cloning a repository on our local machine.
        %git clone <-- some link -->

    ii.status:-display the state of code 
        %git status

    File Status Lifecycle:image

    iii.add:- adds new or changed files in working directory to the Git staging area.
        %git add <-- file name -->

    iv.commit:- it is the record of the change.
        %git commit -m "some message"

    #Note:% git commit -am "you can do both add and commit once you use this"

    v.push:- upload local repo content to remote repo
        %git push origin main

    vi.git init:-used to create a new git repo  
        %git init
    
        %git remote add origin <-link->
        %git remote -v (to verify remote)
        %git branch (to check branch)
        %git branch -M main (to rename branch) 
        %git push origin main

    note: % git push -u origin main ->it set the fixed repo main
            %git push

BRANCH COMMANDS:
    i.  %git branch (to check branch)
    ii. %git branch -M name ( to rename the branch name)
    iii.%git checkout <-branch name -> (to navigate) // %git switch <-branch name->
    iv. %git checkout -b <- new branch name -> (to create new branch)
    v.  %git branch -d <- branch name -> (to delete branch)

REST:
    Representational State Transfer

    REST ia an architechtural style that defines a set of constrainsts to be used for 
    creating web services.
    >REST is like rules for how apps talk over the internet.

    REST in JavaScript?

    When you write JavaScript, and you want to get or send data to a
    server (like showing user info, posts, messages, etc), you use REST API calls.

CRUD Operations:
    GET retrieves resources.
    POST submit new data to the server
    PUT update existing data
    PATCH update existing data partially
    DELETE removes data

Creating RESTful APIs

    GET /posts  to get data for all routes (INDEX(MAIN))

    POST /posts to add a new post (CREATE) 

    GET /posts/:id to get one post(using id ) (VIEW)

    PATCH /posts/:id to update specific post (UPDATE)

    DELETE /posts/:id to delete specific post (DESTROY)

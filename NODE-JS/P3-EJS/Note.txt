Templating:
    EJS(Embedded Javascript templates)
    EJS is a simple templating language that lets you generate HTML markup with plain Javascript.

Using EJS:

    app.set("view engine","ejs"); //templete engine that set ejs

        app.get("/",(req,res)=>{
        res.render("home.ejs");
    })


    Note:views file is search where you start your server

Views Directory:

    const path = require("path");
    
    app.set("views", path.join(__dirname, "views"));
    or,
    app.set("views", path.join(__dirname, "/views"));
Note:   
    __dirname ->is address or current dir  of server i.e  index.js

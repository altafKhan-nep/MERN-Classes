Comparison Operator:
    Comparison operators compare 2 values
   ( >,>=,<,<=,==,!=)
    
    == (compares value, not type)
    eg;true for below:
        "123" == 123 ,1 =='1' ,0 == ' ', 0==false, null == undefined
    ===(compar type and value)
    
    false for below:
     "123" === 123 ,1 === '1' ,0 === ' ', 0 === false, null === undefined

     Comparison for Non Numbers
     'a' > 'A'  //true
     '*' < '&' //false

.if statement:

    if(condition1){
        //do something

          //do something else
    }
    else if(condition3){
          //do something else
    }
.else statement:
    if(condition1){
        //do something 
     }

     }

.Nested if-else:
    Nesting is writing if-else statement inside if-else statements.It can have many levels.
    Eg:
        if marks >= 33
            if marks >= 80 
                print 'o'
            else 
                print 'A'
        else
         print "Better luck next time!"

Logical Operator:
Logical operators to combine expression.

    ||(Logical OR)  (exp1) || (exp2)
    !(Logical Not) !(exp)


truthy & falsy: 
    Everything in js is true or false.(in boolean context).
    This doesn't mean their value is itself true or false,but they are treated as true or false
    if taken in a boolean context.

    falsy value:
    false,0,-0,on(BigInt value),""(empty string),null,undefined,NaN

    truthy value:
    Everything else

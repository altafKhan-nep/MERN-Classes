1. Introduction to DOM:
Concept:
        The DOM represents a document (HTML) as a tree-like structure where each part of the document (like <body>, <div>, <h1>) is a node. You can think of the DOM as a blueprint of your webpage.

Example Structure:



        document(node)
  └─ body(node)
       ├─ div
       │   └─ h1 
       └─ ul
           ├─ li
           ├─ li
           └─ li(node)


        Each part of the HTML document is accessible through this tree structure, allowing JavaScript to modify content, style, and structure dynamically.

2. Selecting Elements:
        Selecting elements is a crucial part of working with the DOM. You need to access elements to change or manipulate them.

    By ID:
      
        document.getElementById("idName");
        Returns: The first element with the given id. If not found, it returns null.

    By Class:

        document.getElementsByClassName("className");
        Returns: A live HTMLCollection of all elements with the specified class name. If not found, an empty collection is returned.

    By Tag Name:

        document.getElementsByTagName("tagName");
        Returns: An HTMLCollection of all elements with the specified tag name (like div, ul, etc.).

    Query Selector (Advanced):

        document.querySelector('p'); // First <p> element
        document.querySelector('#myId'); // First element with id="myId"
        document.querySelector('.myClass'); // First element with class="myClass"
        Returns: The first element that matches the CSS selector.

    eg:
        document.querySelectorAll('p'); // All <p> elements
        Returns: A static NodeList of all matching elements.

Common Confusion:

        getElementById returns a single element, but getElementsByClassName and getElementsByTagName return collections (even if only one element matches).

        querySelector is more flexible as it allows CSS selectors.

3. Using Properties or Methods to Get or Set Data:
        innerText vs textContent:
        innerText: Returns visible text (ignores hidden text).

Eg:
        element.innerText; // "Hello World"
        textContent: Returns all text, including hidden text.

Eg:

        element.textContent; // "Hello World\nAnother line of text"
        innerHTML:
        innerHTML: Returns the HTML inside an element as a string.

Eg:
        element.innerHTML; // "<p>Some <strong>HTML</strong> content</p>"
4. Manipulating Attributes:
        You can get and set the attributes of elements (like src for images, href for links).

Eg:"
        obj.getAttribute('attr'); // Get attribute value
        obj.setAttribute('attr', 'new value'); // Set attribute value
Example:

        let img = document.getElementById('myImage');
        let src = img.getAttribute('src');
        img.setAttribute('src', 'newImage.jpg');

5. Manipulating Styles:
        You can manipulate styles using the style property or by adding/removing classes.

Direct Style Manipulation:
Eg:

        element.style.color = 'red';
        element.style.backgroundColor = 'yellow';
        Using classList:
Eg:
        element.classList.add("newClass");
        element.classList.remove("oldClass");
        element.classList.contains("someClass"); // true/false
        element.classList.toggle("active"); // Adds or removes the class
        
        add(): Adds a class to the element.

        remove(): Removes a class from the element.

        contains(): Checks if the element has a class.

        toggle(): Toggles between adding/removing a class.

6. Navigating the DOM Tree:

        DOM navigation methods allow you to move through the elements.

        parentElement: Get the parent node.

        children: Get the child nodes (but only element nodes).

        childElementCount: Count of child elements.

        previousElementSibling / nextElementSibling: Get the previous or next sibling element.

Eg:
        let parent = element.parentElement;
        let children = element.children;
        let nextSibling = element.nextElementSibling;
7. Adding New Elements:
        You can dynamically create and add new elements to the DOM.

Eg:
        let newElement = document.createElement('p'); // Create a new <p> element
        newElement.textContent = "Hello World"; // Set its content
        document.body.appendChild(newElement); // Add it to the body

Methods for Adding Elements:

        appendChild(element): Adds an element as the last child of a parent.

        append(element): Adds an element or string as the last child.

        prepend(element): Adds an element as the first child.

        insertAdjacentElement(position, element): Inserts an element at a specified position relative to another element.

        Positions for insertAdjacentElement:

        'beforebegin': Before the target element.

        'afterbegin': Just inside the target element, before its first child.

        'beforeend': Just inside the target element, after its last child.

        'afterend': After the target element.

8. Removing Elements:
        You can remove elements using either of these methods:

        removeChild(element): Removes a child element.

        remove(): Removes the element itself.

Eg:
        let parent = document.getElementById('parent');
        let child = document.getElementById('child');
        parent.removeChild(child); // Removes the child from its parent
        child.remove(); // Removes the child element itself

9. Common Mistakes and Confusions:
        getElementById vs. getElementsByClassName:

        getElementById returns a single element, while getElementsByClassName returns a collection (even if only one match exists).

Live vs. Static Collections:

        getElementsByClassName and getElementsByTagName return live collections. This means that if you add or remove elements that match the selector, the collection is automatically updated.

        querySelectorAll returns a static NodeList, which doesn't change when the document changes.

        textContent vs innerText:

        innerText is affected by CSS styles (e.g., display: none), while textContent gives the entire text, including hidden content.

10. Example Q&A to Clarify Concepts:
Q1: What happens if you call document.getElementById('nonexistentId')?
A1: It returns null because the element with the specified ID doesn't exist in the DOM.

Q2: What's the difference between innerText and textContent?
A2: innerText only retrieves visible text and ignores hidden text (e.g., in a <div style="display: none;">), while textContent retrieves all the text inside an element, including hidden ones.

Q3: Can I use querySelector to select an element by class?
A3: Yes, you can. You can use document.querySelector('.className') to select the first element with that class.

Some Examples:

1. Selecting Elements

Example 1: Select by ID
html
Copy
<!-- HTML -->
<div id="myDiv">Hello, World!</div>

<script>
  let myDiv = document.getElementById('myDiv');
  console.log(myDiv.innerText); // Output: "Hello, World!"
</script>

Example 2: Select by Class

html
Copy
<!-- HTML -->
<p class="greeting">Hello, World!</p>
<p class="greeting">Goodbye, World!</p>

<script>
  let paragraphs = document.getElementsByClassName('greeting');
  console.log(paragraphs[0].innerText); // Output: "Hello, World!"
  console.log(paragraphs[1].innerText); // Output: "Goodbye, World!"
</script>

Example 3: Select by Tag Name

html
Copy
<!-- HTML -->
<ul>
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ul>

<script>
  let listItems = document.getElementsByTagName('li');
  console.log(listItems[0].innerText); // Output: "Item 1"
  console.log(listItems[1].innerText); // Output: "Item 2"
  console.log(listItems[2].innerText); // Output: "Item 3"
</script>

Example 4: Using querySelector and querySelectorAll

html
Copy
<!-- HTML -->
<p class="message">This is a message.</p>
<p class="message">This is another message.</p>

<script>
  let firstMessage = document.querySelector('.message');
  console.log(firstMessage.innerText); // Output: "This is a message."

  let allMessages = document.querySelectorAll('.message');
  allMessages.forEach(msg => console.log(msg.innerText));
  // Output:
  // "This is a message."
  // "This is another message."
</script>

3. Manipulating Attributes

Example 1: Using getAttribute and setAttribute

html
Copy
<!-- HTML -->
<img id="myImage" src="oldImage.jpg" alt="Old Image">

<script>
  let img = document.getElementById('myImage');

  // Get current attribute value
  console.log(img.getAttribute('src')); // Output: "oldImage.jpg"

  // Set new attribute value
  img.setAttribute('src', 'newImage.jpg');
  console.log(img.getAttribute('src')); // Output: "newImage.jpg"
</script>

4. Manipulating Styles

Example 1: Changing Inline Styles

html
Copy
<!-- HTML -->
<p id="styledText">This is a styled paragraph.</p>

<script>
  let p = document.getElementById('styledText');
  p.style.color = 'red'; // Change the text color to red
  p.style.fontSize = '20px'; // Set font size to 20px
</script>

Example 2: Using classList to Add/Remove Classes

html:

<!-- HTML -->
<p id="text">This is a styled paragraph.</p>

<script>
  let p = document.getElementById('text');

  // Add a class
  p.classList.add('highlight'); // This will add the "highlight" class to the paragraph

  // Remove a class
  p.classList.remove('highlight'); // This will remove the "highlight" class

  // Toggle a class (add if not exists, remove if exists)
  p.classList.toggle('highlight'); // Adds the class if it's not present
</script>

<!-- CSS -->
<style>
  .highlight {
    background-color: yellow;
    color: red;
  }
</style>

5. Navigating the DOM

Example 1: Using parentElement, children, nextElementSibling, and previousElementSibling

html

<!-- HTML -->
<div id="parent">
  <p>First paragraph</p>
  <p>Second paragraph</p>
  <p>Third paragraph</p>
</div>

<script>
  let parentDiv = document.getElementById('parent');
  let firstParagraph = parentDiv.children[0]; // Accessing the first <p> child

  console.log(firstParagraph.innerText); // Output: "First paragraph"
  
  // Accessing next sibling element
  let nextParagraph = firstParagraph.nextElementSibling;
  console.log(nextParagraph.innerText); // Output: "Second paragraph"

  // Accessing previous sibling element
  let previousParagraph = nextParagraph.previousElementSibling;
  console.log(previousParagraph.innerText); // Output: "First paragraph"
  
  // Accessing the parent element
  let parent = firstParagraph.parentElement;
  console.log(parent.id); // Output: "parent"
</script>

6. Adding and Removing Elements

Example 1: Creating and Appending a New Element

html
Copy
<!-- HTML -->
<div id="container"></div>

<script>
  let container = document.getElementById('container');

  // Create a new <p> element
  let newPara = document.createElement('p');
  newPara.innerText = "This is a new paragraph!";

  // Append the new element to the container
  container.appendChild(newPara);
</script>

Example 2: Inserting Elements with insertAdjacentElement

html

<!-- HTML -->
<div id="parent">
  <p>First paragraph</p>
</div>

<script>
  let parent = document.getElementById('parent');
  let newPara = document.createElement('p');
  newPara.innerText = "This is an inserted paragraph.";

  // Insert the new paragraph before the first child element
  parent.insertAdjacentElement('beforebegin', newPara);
</script>

Example 3: Removing an Element

html
Copy
<!-- HTML -->
<div id="container">
  <p id="removeMe">This paragraph will be removed.</p>
</div>

<script>
  let para = document.getElementById('removeMe');

  // Remove the element
  para.remove();
</script>

7. Combining Multiple Operations

Example: Dynamic List of Items (Add, Remove, Toggle)

html
Copy
<!-- HTML -->
<ul id="todoList">
  <li>Buy groceries</li>
  <li>Clean the house</li>
  <li>Walk the dog</li>
</ul>

<button id="toggleButton">Toggle Items</button>

<script>
  let listItems = document.querySelectorAll('#todoList li');
  let toggleButton = document.getElementById('toggleButton');

  toggleButton.addEventListener('click', () => {
    listItems.forEach(item => {
      item.classList.toggle('completed'); // Toggle "completed" class
    });
  });
</script>

<!-- CSS -->
<style>
  .completed {
    text-decoration: line-through;
    color: gray;
  }
</style>

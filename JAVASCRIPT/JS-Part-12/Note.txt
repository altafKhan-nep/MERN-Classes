ASYNC FUNCTION:
    *async & await keywords 
    >async and await are syntactic sugar built on top of Promises, 
        making asynchronous code look more like synchronous code.
    >An async function always returns a Promise.
    >await pauses the execution of an async function until the Promise is resolved.

    
    Async keyword:
        create an Async function 
        ex: 
            async function greet(){
                return "Assalmualikum"; //returns a promises
                }
            .then((result)=>{
                     console.log("Promises was resolved");
                     console.log("Result was :",result);
                    })
            .catch((error)=>{
                     console.log("Promises was rejected with result :",error)
                    })

        let hello = async ()=>{} //returns a promises

NOTE: 
    function normal ->returns promises:fulfilled & it's value.
    function error ->return promises:rejected & error value

Await keyword:
Handling Rejections with Await 
Ex in js2.


//Example -1
let url = "https://catfact.ninja/fact";


fetch(url)
.then(res=>res.json())
.then(data=>{
    console.log("Cat fact: ",data.fact);
})
.catch(e=>{
    console.log("Error ",e);
})

//Example-2 using async/await version (even simpler)

async function getFact() {
    let res = await fetch("https://catfact.ninja/fact");
    let data = await res.json();
    try{
        console.log("Cat fact :",data.fact)
    }
    catch(er){
        console.log("Err ",er)
    }
}

getFact();

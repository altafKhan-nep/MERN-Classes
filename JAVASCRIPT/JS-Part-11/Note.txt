PROMISES:(object)

    The promises object represents the eventual completion (or failure) of an 
    asynchronous opration and it's resulting value.
    resolve(sucess) & reject(failed)
    Promises
    >Promises are a way to handle asynchronous operations more cleanly. 
         A Promise represents a value that may be available now, in the future, or never.

        States of a Promise:

            Pending: Initial state, neither fulfilled nor rejected.

            Fulfilled: The operation completed successfully.

            Rejected: The operation failed.


    Examples:

    function saveToDb(data){
    return new Promise((resolve,reject) => {
        let internet = Math.floor(Math.random()*10) + 1;
         if(internet >4){
            resolve("Data saved successfully!");
         }else{
            reject("Weak connection :data failed to save!");
         }
    });

}

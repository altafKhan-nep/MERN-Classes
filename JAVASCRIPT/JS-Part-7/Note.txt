this  Keyword:
    "This" keyword refers to an object that is executing the  current piece of code.  

try & catch :
    The try statement allows you to define a block of code to be tested for errors while it is being executed.

The catch statement allows you to define a block of code to be executed, if an error occurs in the try block 

note: callback is function that passes as argument or parameter  of the other function.

MISCELLANEOUS TOPICS:
Arrow Function:

const funcName = (arg1,arg2 ....) => {
        //function defination
    }

    Eg:
    const sqr = n =>{
        console.log(n**2);
    }
    const hello = () =>{
        console.log("hello ,world");
    }
    const sum = (a,b) =>{
        console.log(a+b);
    }

Implicit return:
    const func = (arg1,arg2..) =>(values);
Eg: const mod = (a,b) =>(a%b);

Set Timeout:
    >the callback function execute after timeout!
    setTimeout(function,timeout) //function --> callback : timeout --> time in millisecond(ms);

Set Interval:
    >the callback function executed after every timeout or interval!
    setInterval(func,interval or timeout)


to stop the function : clearInterval(id)
        eg: let id = setInterval(func,interval or timeout);
